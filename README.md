# Live Enhance Lights

観客のスマホがそのまま**ペンライト（発光面）**になる、ライブ演出用の Web アプリ。
**アプリ不要**（ブラウザで URL / QR を開くだけ）。マスター（プレゼンター）が手元の
コンソールから**コマ送りでシーンを切り替える**と、会場中のスマホがリアルタイムに
一斉に光ります。音源同期は行わないので、曲構成に合わせて手動で進行できます。

「アプリ不要・演出側の中央制御」を、**事前プログラム＋手動進行**に特化して実装したものです。

> 📖 当日の操作方法・運用フローは **[docs/manual.md](docs/manual.md)（使い方ガイド）** を参照。

## 主な機能

- **観客画面 (`/`)**: 自己申告フォローゲート → 全画面発光。明滅/ストロボ/グラデ/レインボー/
  テキスト/画像/暗転に対応。スリープ防止（Wake Lock）とタップで全画面化。
- **マスターコンソール (`/master`)**:
  - **本番モード / 編集モード**の切替
  - 曲ごとに **4×3 = 12 個の名前付きシーンボタン**
  - 各ボタンにシーン（色・パターン・**BPM**・**繰り返し**）を割り当て、名前を付与
  - **テキスト**は改行・システムフォント選択・サイズ選択に対応
  - **画像**は Cloudflare R2 へアップロード（自動縮小）or URL 指定。全体表示/トリミング選択
  - 明滅/ストロボは**色1↔色2の2色切替**（色2を黒にすれば増減光）
  - 本番モードでボタンを押すと全端末がそのシーンに切替（押下ボタンをハイライト）
  - **MIDI操作**（Chrome/Edge）：Program Change=曲切替 / Control Change=シーン発火
  - 接続台数の表示、暗転ボタン、現在出力の**スマホ縦長**プレビュー、参加用 QR
  - セットリストの JSON 書き出し/読み込み
- **アニメーションは各端末側で描画**するため、サーバへ送るのは切替時の 1 メッセージだけ。
  同期基盤（Ably）の従量課金をほぼゼロに抑えます。
- **光過敏性への配慮**: ストロボ点滅は 3Hz 上限にクランプ。入場前に注意書きを表示。

> Instagram のフォロー判定は公式 API では第三者アプリが取得できないため、
> 「フォローした → 入場」の**自己申告ゲート**方式にしています。

## セットアップ（ローカル）

```bash
npm install
cp .env.example .env.local   # 必要に応じて編集
npm run dev                  # http://localhost:3000
```

`.env` を設定しない場合は **デモモード**で動きます（同一ブラウザの複数タブ間だけで同期）。
`/master` を開き、パスコード（既定 `0000`）で入室 → 別タブで `/` を開くと挙動を確認できます。

## 本番（複数スマホで同期）

スマホ間同期には [Ably](https://ably.com) を使います。

1. Ably でアプリを作成し API キーを取得
2. 環境変数を設定
   ```
   ABLY_API_KEY=＜Ablyのキー＞
   NEXT_PUBLIC_ABLY_ENABLED=1
   NEXT_PUBLIC_SHOW_ID=your-band
   NEXT_PUBLIC_SHOW_TITLE=バンド名 / ツアー名
   NEXT_PUBLIC_INSTAGRAM_URL=https://www.instagram.com/＜アカウント＞/
   NEXT_PUBLIC_MASTER_PASSCODE=＜任意のコード＞
   ```
   `ABLY_API_KEY` はサーバ側のみで使用し、クライアントには `/api/ably/token` 経由の
   短命トークンだけを渡します（キーは露出しません）。
3. Vercel などにデプロイ（`ABLY_API_KEY` を含む上記を環境変数に登録）
4. `/master` を関係者だけに共有。観客には `/`（＝コンソールの参加用 QR）を提示。

複数の公演で使い回す場合は URL に `?show=別ID` を付けると別チャンネルになります
（`/?show=xxx` と `/master?show=xxx` を合わせてください）。

## コストの目安（最大 300〜400 台想定・3〜5 曲）

- 手動コマ送り＝送信メッセージが極小のため、**従量課金はほぼ発生しません**。
- 実費は「同時接続をさばく同期基盤の月額固定費」がほぼすべて。
- **Ably Standard**（$29/月＋わずかな従量）＋ Vercel（Hobby 無料 / 商用は Pro $20）で
  月 **約 ¥4,000〜7,000**。課金は**公演がある月だけ**にすれば年間コストは小さく抑えられます。
- ※ Ably / Vercel とも無料枠の同時接続上限は 200。400 台想定では有料化が必要です。

## 技術構成

- Next.js (App Router) + TypeScript
- リアルタイム同期: Ably（`src/lib/transport.ts` で抽象化。未設定時は BroadcastChannel）
- 演出データ: JSON（マスター端末の localStorage に保存 / JSON で書き出し・読み込み）
